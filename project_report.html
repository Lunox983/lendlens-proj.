4. นวัตกรรมและจุดเด่นของระบบ (Key Innovations)

🚀 1. ระบบคิวอัจฉริยะแบบอัตโนมัติ (Smart Queue Auto-Calling System)

เมื่อมีผู้ใช้งานนำอุปกรณ์มาคืน ระบบจะค้นหาว่ามีนักศึกษาที่เข้าคิวรออุปกรณ์ชิ้นนี้อยู่หรือไม่ หากมี ระบบจะเรียกคิวแรกสุดโดยอัตโนมัติ พร้อมส่ง Email และ Notification แจ้งเตือนทันที โดยนักศึกษาจะมีเวลา 5 นาทีในการมารับอุปกรณ์ หากไม่มา ระบบจะตัดคิวและเรียกคนถัดไปให้เอง (Auto-Skip) ลดภาระแอดมินในการคอยโทรตาม

⚡ 2. การซิงโครไนซ์ข้อมูลแบบ Real-time

ระบบใช้เทคโนโลยี WebSockets (Socket.IO) ในการเชื่อมต่อ หากนักศึกษาคนหนึ่งกดยืมอุปกรณ์จนหมด หน้าจอของนักศึกษาคนอื่นที่เปิดค้างไว้จะอัปเดตยอดคงเหลือเป็น "0" ในทันที ป้องกันปัญหาการจองซ้อนทับกัน (Race Condition) ได้อย่างสมบูรณ์แบบโดยที่ผู้ใช้ไม่ต้องกดปุ่ม Refresh

📦 3. ระบบติดตามไอเท็มย่อยแบบไดนามิก (Dynamic Asset Item Tracking)

การสร้างอุปกรณ์ 1 ชิ้นที่มีจำนวน 10 ตัว ระบบจะสร้างรหัสครุภัณฑ์ (Asset Code) ย่อยให้ 10 รายการอัตโนมัติ เมื่อกดยืม ระบบจะล็อกไอเท็มชิ้นที่ยัง 'ว่าง' ให้กลายเป็น 'ถูกยืม' และเมื่อรับคืนแบบ 'เสียหาย' ระบบจะล็อกไอเท็มชิ้นนั้นให้เป็น 'งดใช้ชั่วคราว' ทำให้ควบคุมจำนวนคงเหลือ (Available Quantity) ได้ตรงตามความจริง

📱 4. Unified Barcode & QR Scanner

แอดมินไม่จำเป็นต้องใช้ฮาร์ดแวร์แสกนเนอร์ราคาแพง หน้าเว็บใช้กล้องเว็บแคมหรือสมาร์ทโฟนแสกน QR Code ของใบเสร็จ หรือ บาร์โค้ดของอุปกรณ์ได้ในปุ่มเดียว เมื่อแสกนปุ๊บ ระบบจะวิเคราะห์เองว่านี่คือ QR Code สำหรับ "จ่ายของให้คิว" หรือ "รับของคืน" และประมวลผลทันที ลดขั้นตอนการทำงานลงมากกว่า 80%

sequenceDiagram actor S as นักศึกษา participant FE as Frontend (React) participant API as Backend (Express) participant DB as MySQL Database participant EM as Email Service S->>FE: 1. เลือกอุปกรณ์ + กดยืนยันยืม FE->>API: POST /api/borrow API->>DB: INSERT INTO borrowed (status=pending) DB-->>API: OK (borrow_id) API-->>FE: สำเร็จ + QR Code FE-->>S: แสดงใบเสร็จ + QR Note over S,EM: --- รอ Admin อนุมัติ --- actor A as ผู้ดูแลระบบ A->>FE: 2. ดูรายการรออนุมัติ FE->>API: GET /api/admin/requests API->>DB: SELECT borrowed WHERE status=pending DB-->>API: รายการคำขอ API-->>FE: แสดงรายการ FE-->>A: แสดงคำขอ A->>FE: 3. กดอนุมัติ FE->>API: POST /api/admin/update-request (approve) API->>DB: BEGIN TRANSACTION API->>DB: UPDATE equipment_items SET status=borrowed API->>DB: UPDATE borrowed SET status=borrowed API->>DB: COMMIT DB-->>API: OK API->>EM: ส่ง Email แจ้ง "อนุมัติแล้ว" API-->>FE: สำเร็จ API->>FE: Socket.IO emit data_updated FE-->>S: อัปเดต UI แบบ Real-time

8.2 กระบวนการคืนอุปกรณ์ (Return Equipment Flow)

sequenceDiagram actor A as ผู้ดูแลระบบ participant FE as Frontend (React) participant API as Backend (Express) participant DB as MySQL Database participant EM as Email Service actor S as นักศึกษา A->>FE: 1. แสกนบาร์โค้ดอุปกรณ์ FE->>API: POST /api/admin/return_by_barcode API->>DB: BEGIN TRANSACTION API->>DB: ค้นหา borrowed ที่ตรงกับบาร์โค้ด DB-->>API: พบรายการยืม API->>DB: UPDATE borrowed SET status=returned API->>DB: UPDATE equipment_items SET status=available API->>DB: COMMIT DB-->>API: OK API->>EM: ส่ง Email แจ้ง "คืนสำเร็จ" EM-->>S: ได้รับ Email Note over API,DB: ตรวจสอบว่ามีคนรอคิวหรือไม่ API->>DB: SELECT equipment_queue WHERE status=waiting DB-->>API: พบคนรอคิว API->>DB: UPDATE queue SET status=called API->>DB: INSERT INTO notifications API->>EM: ส่ง Email แจ้ง "ถึงคิวของคุณแล้ว" API->>FE: Socket.IO emit data_updated FE-->>A: อัปเดต UI สำเร็จ

8.3 กระบวนการเข้าคิว (Queue Flow)

sequenceDiagram actor S as นักศึกษา participant FE as Frontend (React) participant API as Backend (Express) participant DB as MySQL Database participant EM as Email Service S->>FE: 1. กด "ต่อคิว" อุปกรณ์ที่หมด FE->>API: POST /api/queue/join API->>DB: ตรวจสอบว่าเข้าคิวซ้ำหรือไม่ DB-->>API: ยังไม่เคยเข้าคิว API->>DB: INSERT INTO equipment_queue DB-->>API: OK (queue position) API-->>FE: เข้าคิวสำเร็จ ลำดับที่ N FE-->>S: แสดงตำแหน่งคิว Note over S,EM: --- เมื่อมีคนคืนอุปกรณ์ --- API->>DB: เรียก callNextInQueue() API->>DB: UPDATE queue SET status=called, expires_at=+5min API->>DB: INSERT INTO notifications API->>EM: ส่ง Email "ถึงคิวของคุณแล้ว" EM-->>S: ได้รับ Email API->>FE: Socket.IO emit data_updated FE-->>S: แจ้งเตือน "ถึงคิว - รับของภายใน 5 นาที" alt มารับทันเวลา S->>FE: แสดง QR Code FE->>API: POST /api/admin/pickup_queue API->>DB: UPDATE queue SET status=completed API->>DB: INSERT INTO borrowed (status=borrowed) API-->>FE: จ่ายของสำเร็จ else ไม่มารับภายใน 5 นาที API->>DB: Cron: UPDATE queue SET status=expired API->>DB: เรียก callNextInQueue() คนถัดไป end
